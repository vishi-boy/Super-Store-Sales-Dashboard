# Super-Store-Sales-Dashboard
📌 Project Overview

This project is an interactive Power BI Sales Dashboard built using the SuperStore dataset. The dashboard provides insights into sales performance, profit trends, customer purchasing behavior, regional performance, and future sales forecasting.

The objective of this project is to help businesses monitor KPIs, identify sales trends, and make data-driven decisions through effective data visualization.

🚀 Key Features
Sales Analysis Dashboard
Total Sales analysis by Region
Sales distribution by Segment
Sales by Payment Mode
Monthly Sales Trend (Year-over-Year)
Monthly Profit Trend (Year-over-Year)
Sales by Ship Mode
Sales by Category
Sales by Sub-Category
State-wise Sales Map Visualization
Region-wise filtering and interactive slicers
Sales Forecasting Dashboard
Time Series Sales Analysis
15-Day Sales Forecast using Power BI Forecasting
State-wise Sales Performance
Historical vs Predicted Sales Comparison
Trend Identification and Future Sales Prediction

🛠️ Tools & Technologies Used
Power BI
Power Query
DAX (Data Analysis Expressions)
Data Modeling
Forecasting Analytics
Interactive Visualizations

📈 Dashboard Insights
West Region generated the highest sales contribution.
Consumer Segment contributed the largest share of total sales.
COD was the most preferred payment method.
Office Supplies category recorded the highest sales.
Sales and profit showed significant growth during the last quarter of the year.
Forecasting indicates expected sales trends for the upcoming 15 days.
